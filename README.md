# 🧵 Textile & Garment Cost Calculator

An interactive web application built with **Streamlit** for calculating FOB costs, profit margins, overheads, and manufacturing breakdowns in textile production.

## 🚀 Features
- **Raw Material & Processing Costs:** Calculate yarn rates, fabric consumption, and knitting/dyeing charges.
- **CMT & Accessories:** Account for stitching (CMT), trims, packaging, and logistics.
- **Dynamic Profit Margins:** Interactively adjust profit margins and factory overhead allowances.
- **Visual Cost Breakdown:** View pie chart visualizations and percentage allocations per garment unit.
- **Quotation Export:** Export cost breakdowns directly to CSV.
